# recap: 내가 이해한 대로 되짚기

사용자가 이것저것 말한 뒤 부르는 스킬이다. 목적은 일을 더 하는 것이 아니라, **AI가 이해한 내용이 맞는지 사용자가 바로 확인하게 하는 것**이다. 어긋난 이해는 일을 시작하기 전에 잡는 편이 훨씬 싸다.

## Workflow

1. 지금까지의 대화(와 사용자가 언급한 파일)를 다시 읽는다. 새로운 조사나 작업은 하지 않는다. 도구는 사용자가 언급한 파일을 읽을 때만 쓴다.
2. 아래 형식으로, 전체 8줄 안팎의 짧은 요약을 쓴다.

   **목표**: 사용자가 결국 이루고 싶은 것 한 문장.
   **풀려는 문제**: 지금 그 목표를 가로막는 것 한 문장.
   **지금까지**: 한 일, 정해진 것 (있으면 2~3개).
   **내가 가정한 것**: 사용자가 말하지 않았지만 내가 채운 부분 (있으면 1~2개). 이 부분이 가장 자주 틀린다.
   **아직 모르는 것**: 일을 시작하려면 필요한데 답이 없는 것 (있으면 1~2개).

3. 마지막에 "틀린 부분이 있으면 알려 주세요" 한 줄로 끝낸다. 이어서 일을 시작하지 않고 사용자의 정정을 기다린다.

## Principles

- 사용자의 말을 그대로 다시 읊지 않는다. 사용자가 한 말에서 **목표와 문제**를 뽑아 내가 이해한 형태로 쓴다. 그래야 이해의 차이가 드러난다.
- 모르는 것을 아는 척 채우지 않는다. 비어 있으면 "내가 가정한 것"이나 "아직 모르는 것"에 솔직히 적는다.
- 길게 쓰지 않는다. 빈 항목은 쓰지 않고 줄을 줄인다.
- 사용자와 같은 언어로 쓴다.
